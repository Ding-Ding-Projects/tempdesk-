# 功能驗證清單

[English](FEATURE-INVENTORY.md)

用呢份清單查閱 TempDesk 各項工作嘅驗證進度。[完整記錄](feature-inventory.json)列出適用範圍、觀察結果、證據同未完成嘅工作。每項結果都對應指定介面同原始碼版本。

## 按工作搵資料

- 部署或者更新電腦程式，先睇[部署程式](../deployer/README.md)嘅安裝同初次使用指引。
- 建立臨時帳戶同檢查到期時間，可以參考[自助服務站示範](../README.md#guest-sign-in-walkthrough)同[入口功能狀態](../portal/FEATURES.md)。訪客入口、管理入口同實際運行嘅自助服務站各有自己嘅驗證記錄。
- 借用遠端工作階段，睇 [Virtual Commons 指引](VIRTUAL-COMMONS.md)。每個版本都要分別檢查主機、連線檔、登入同到期處理。
- 冇網絡嗰陣可以用[離線文件閱讀器](OFFLINE-GUIDE.md)。公開網站同離線閱讀器有各自嘅驗證結果。

## 比較各個介面嘅進度

已建置嘅文件會由完整清單計算下面嘅數字。用表格嘅搜尋欄可以搵到要查嘅介面。

<!-- feature-inventory-summary -->

- **已驗證**有實際運行、發布或者交付證據。
- **部分完成**有指定範圍嘅結果，亦列出未完成嘅工作。
- **待處理**仲需要審核、開發或者驗證。
- **不適用**喺清單嘅範圍設定有寫明原因。同一功能可以適用於其他介面。

新增證據嗰陣，請寫明相關功能、介面同原始碼版本。之前嘅記錄要保留當時嘅適用範圍。
