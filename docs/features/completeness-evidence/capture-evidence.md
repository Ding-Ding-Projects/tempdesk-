# Review captures and recordings

The [feature inventory](../../FEATURE-INVENTORY.md) links source-bound screenshot groups for guest sign-in, Virtual Commons, management preferences and notifications, and offline documentation. Historical portal images also have their own [provenance record](../../evidence/portal-history.md).

The evidence audit checks the existing file bytes against each screenshot digest and requires an inspected record with an explicit source revision, artifact digest, viewport, scale, theme and interaction receipt digest. A capture is a candidate match only when its source revision and artifact digest both match the selected candidate and the original record remains active. All other captures retain their historical classification.

Inspect the candidate's workflow and pixels before using a matching capture to describe it. Record consent and privacy constraints, and keep original files and provenance for older releases. A current end-to-end recording, full surface coverage, and live public gallery verification remain outstanding.
