# Security policy

See [TempDesk's operator security guide](docs/SECURITY.md) for network placement, credentials, permissions and guest-account limits.

Report a suspected vulnerability through [private vulnerability reporting](https://github.com/Ding-Ding-Projects/tempdesk-/security/advisories/new) if enabled. When it is unavailable, request a private channel from the maintainers before sharing details. Leave credentials, deployment addresses and user records out of all reports.
